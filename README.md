# btm-game


## Pages

### [main.html](https://dewanik.github.io/btm-game/main.html)
This is the main game page of btm-game. It is a complete playable infinite driving game (like "Biratamode Infinite Drive") rendered in 3D using Three.js. The player controls a vehicle navigating on a looping course with randomly placed obstacles and buildings. The object is to travel as far as possible, avoiding obstacles, and to achieve a high score. The page includes features like a minimap, movement controls, speedometer, and score tracking.

### [btm.html](https://dewanik.github.io/btm-game/btm.html)
This is a demonstration or prototype page titled "Biratamode Monument Reconstruction." It renders a static or semi-interactive 3D visualization of a monument, focusing on rotation and scrolling the camera around the object using mouse or keyboard controls. The page is used to show off 3D modeling and rendering skills rather than being a full game.
